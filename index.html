Salesforce Merge Tool

Maharishi Foundation Australia

Converts a Brevo newsletter export for Salesforce with the smallest possible edit: merge fields become {!Contact.X} syntax, the unsubscribe link points at Salesforce, and the dead "view in browser" link and hidden tracking junk are removed. Everything else — layout, colors, buttons, images — stays exactly as you built it.

Salesforce List Email has silently truncated real sends above roughly 25 KB in the past. This tool no longer restructures your HTML to fight that — it makes the smallest possible edit instead, so large newsletters may still need to be split manually. Always send a real test before a full list send.
